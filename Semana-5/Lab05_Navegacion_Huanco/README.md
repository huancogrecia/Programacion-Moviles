# Lab05 - Navegacion - Huanco

## Descripción
La aplicación cuenta con cuatro pantallas principales:

- Pantalla de inicio.
- Lista de 8 elementos.
- Detalle del elemento seleccionado.
- Perfil del estudiante.

## Mejora con IA
### Prompt utilizado
Quiero que te comportes como un desarrollador de aplicaciones móviles con experiencia en Kotlin y Jetpack Compose, tengo conocimientos básicos de programación móvil y quiero mejorar únicamente el diseño visual de mi proyecto, ahora tengo una pantalla de inicio, una lista de 8 elementos, una pantalla de detalle y una de perfil, quiero que se vean más modernas, ordenadas y atractivas usando componentes sencillos de Jetpack Compose. Considera no cambiar la navegación, las rutas, el paso del itemId ni la funcionalidad actual de la aplicación, mantén el código lo más sencillo posible y explícame los cambios paso a paso
