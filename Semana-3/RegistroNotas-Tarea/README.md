## Estudiante

## Descripción
Aplicación desarrollada en Kotlin con Jetpack Compose para registrar las notas de cuatro cursos y calcular el promedio ponderado

La aplicación permite seleccionar las notas mediante Slider, confirmar los datos, redondear el promedio final y mostrar una observación según el resultado obtenido

## Funcionalidades

- Registro de notas de 0 a 20 mediante Slider
- Cálculo del promedio ponderado
- Switch para redondear el promedio final
- Checkbox para confirmar las notas
- Botón para calcular el promedio
- Resultado con observación: EXCELENTE, APROBADO, EN RECUPERACIÓN o DESAPROBADO
