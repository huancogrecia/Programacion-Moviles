# Laboratorio 06 - TECSUP Store

## Descripción

En este laboratorio continué con el proyecto TECSUP Store trabajado en las semanas anteriores. Agregué un DropdownMenu en cada producto y un NavigationDrawer para navegar entre las diferentes secciones de la aplicación.

## Funcionalidades

- Menú de tres puntos en cada producto.
- DropdownMenu con las opciones Favoritos, Compartir y Reportar.
- Íconos y separadores dentro del DropdownMenu.
- NavigationDrawer como menú principal.
- Navegación entre Inicio, Mis pedidos, Favoritos y Perfil.
- Encabezado del Drawer con los datos del usuario.
- Opción actual del Drawer resaltada.

## Preguntas de reflexión

### 1. ¿Por qué el DropdownMenu se declara dentro de un Box junto al ícono que lo activa, y no en cualquier parte de la pantalla?

Porque el DropdownMenu pertenece al producto donde se encuentra el botón de tres puntos. Al colocarlos juntos dentro de un Box, el menú aparece relacionado con ese producto.

### 2. ¿Qué diferencia de alcance hay entre las opciones del DropdownMenu y las del NavigationDrawer?

El DropdownMenu permite realizar acciones sobre un producto específico, como agregarlo a Favoritos, compartirlo o reportarlo. En cambio, el NavigationDrawer permite navegar entre las secciones principales de toda la aplicación.

## Observaciones

- Observé que el DropdownMenu permite mostrar varias acciones de un producto sin ocupar mucho espacio en la pantalla.
- Observé que el NavigationDrawer facilita el acceso a las diferentes secciones de la aplicación.

## Conclusiones

- Aprendí a implementar y personalizar un DropdownMenu en los productos.
- Aprendí a utilizar un NavigationDrawer como menú principal de navegación.
