# PROMPTS UTILIZADOS CON IA

## Prompt 1 - Mejora de la pantalla Inicio
Actúa como un programador de aplicaciones móviles, considera que tengo un poco de experiencia pero todavía estoy aprendiendo y quiero que mejores visualmente la pantalla de inicio de mi aplicación TECSUP Fit sin cambiar mucho el código ni la funcionalidad que ya tengo, mantén el título, el saludo, los filtros y las clases actuales, mejora principalmente el encabezado y la presentación de las tarjetas de cada clase, puedes agregar imágenes o elementos visuales sencillos para darle una apariencia más deportiva, moderna y ordenada, pero manteniendo el código simple y fácil de entender


## Prompt 2 - Mejora de Detalle de clase
Ahora mejora visualmente la pantalla de detalle de la clase, mantén la información y funcionalidad actual y sigue el mismo estilo deportivo de la pantalla de inicio, organiza mejor los datos y el botón de reserva sin complicar el código


## Prompt 3 - Mejora de las demás pantallas
Ahora mejora visualmente las pantallas de Confirmación, Reservas, Rutinas y Perfil, además de la barra de navegación inferior. Mejora los colores, tarjetas, botones, iconos y la organización visual para que tengan el mismo estilo deportivo de Inicio y Detalle. Mantén el código, la estructura, los datos y la funcionalidad actual, realiza únicamente cambios visuales y sencillos


## Prompt 4 - Reservas dinámicas
Ahora mejora el funcionamiento de las reservas para que, cuando reserve una clase, esa misma clase aparezca en la pantalla de Reservas como Confirmada. Mantén el código y la estructura que ya tenemos, realiza solo los cambios necesarios y conserva el diseño actual de la aplicación
