# Control de Préstamos

Programa desarrollado en Kotlin para registrar el préstamo de un libro.
Permite seleccionar el tipo de usuario (Alumno o Docente), registrar las fechas de préstamo, entrega y devolución, calcular los días de atraso y aplicar una multa de S/ 1.50 por día.

## Funciones principales
- Registro del préstamo
- Selección de Alumno o Docente
- Cálculo de días de atraso
- Cálculo de multa
- Estado de la devolución
